what techstack we will be using

So far, we have initialized the ORdine project with a separate frontend and backend structure. For the frontend, we chose React with Vite (JavaScript) instead of Create React App because it is faster, modern, and the current standard for React development. For the backend, we decided to use FastAPI (Python) instead of Express.js because it provides excellent performance, automatic API documentation, built-in request validation, and is well-suited for future enhancements like AI features. Our database will be PostgreSQL, accessed through SQLAlchemy ORM, with Alembic for database migrations. Authentication will use JWT with Passlib (bcrypt) for password hashing. Product images will be stored on Cloudinary, QR codes will be generated using Python's qrcode library and scanned on the frontend using html5-qrcode, and FastAPI WebSockets will be used to deliver real-time order updates between customers and restaurant admins. We also created the backend directory, created a Python virtual environment (venv), and began installing the initial FastAPI dependencies, although we still need to finish configuring the virtual environment correctly before continuing with backend development.
